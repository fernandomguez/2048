Bienvenido a 2048

Desliza las fichas para moverlas (en PC, usa las flechas del teclado). Cuando dos fichas del mismo número se juntan, se fusionan y se suman. El objetivo es seguir sumando hasta conseguir la ficha 2048.

Novedades de esta versión

  • ↩︎ Puedes deshacer tus movimientos (3 usos).
  • 💣 Tienes una bomba para eliminar una ficha.
  • ✨ Las fichas se animan al moverse y los puntos +N flotan sobre la fusión.
  • 🔊 Sonido y vibración al fusionar: actívalos con el interruptor Sonido.
  • 💾 Tu partida en curso se guarda sola y vuelve al recargar.
  • 📲 En iPhone/iPad: Compartir → Añadir a pantalla de inicio para instalarla.

El juego necesita un servidor local

Lo estás abriendo como archivo (file://) y el navegador bloquea la carga de los módulos JavaScript.

Ejecuta esto en la carpeta del proyecto:

npm start

y abre http://localhost:8000

Alternativa con Python: python -m http.server 8000
